# Data and Model Sources

## SciFact and BEIR

The experiment uses BEIR's SciFact retrieval dataset: 5,183 documents and 300 test queries. The test split is the BEIR retrieval-task split, not the hidden test set of the original SciFact claim-verification task.

- [BEIR SciFact archive](https://public.ukp.informatik.tu-darmstadt.de/thakur/BEIR/datasets/scifact.zip)
- [Original SciFact project](https://github.com/allenai/scifact)
- [BEIR retrieval benchmark](https://github.com/beir-cellar/beir)
- [BeIR/scifact dataset card](https://huggingface.co/datasets/BeIR/scifact)

SciFact was created by David Wadden, Shanchuan Lin, Kyle Lo, Lucy Lu Wang, Madeleine van Zuylen, Arman Cohan, and Hannaneh Hajishirzi. The original paper is [Fact or Fiction: Verifying Scientific Claims](https://arxiv.org/abs/2004.14974).

The [original SciFact license notice](https://github.com/allenai/scifact/blob/master/LICENSE.md) labels claims and evidence annotations as CC BY 4.0 and abstracts from S2ORC as ODC-By 1.0. The BEIR Hugging Face dataset card separately labels the dataset CC BY-SA 4.0. These are the notices published by the respective upstream sources; including third-party data here does not change its applicable license.

This repository does not distribute the full corpus or dataset archive. `recorded-results/retrieval_*.json` contains public query text, document IDs, relevance judgments, and retrieval rankings. `http_example_*.json` contains a small number of public document titles and retrieval scores. These are benchmark outputs, not production user or customer records. Text and judgments come from the public dataset; rankings and metrics were generated by this experiment.

## Embedding models

- [BAAI/bge-small-en-v1.5](https://huggingface.co/BAAI/bge-small-en-v1.5): 384 dimensions.
- [BAAI/bge-base-en-v1.5](https://huggingface.co/BAAI/bge-base-en-v1.5): 768 dimensions.

The BAAI model pages list the MIT License. This experiment loads the original BAAI weights through the [Milvus model library](https://github.com/milvus-io/milvus-model), using its Sentence Transformers integration with PyTorch FP32 inference on CPU. Model weights are not included. The pinned model revisions, downloaded file hashes, and inference configuration are recorded in `recorded-results/model-provenance.json`. The Milvus model library is distributed under Apache-2.0; its dependencies retain their respective licenses.

## Dependencies and containers

Python dependency versions are pinned in `requirements.lock.txt`; container image versions are specified in `docker-compose.yml`. Dependencies, datasets, models, and container images remain subject to their respective upstream licenses.
